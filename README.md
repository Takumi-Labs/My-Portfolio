Getting Started
Clone the repository:
bash
git clone https://github.com/MARIAMMUDASIRU/portfolio.git
Move into the project folder:
bash
cd portfolio
Open index.html in your browser, or use a local server such as the VS Code Live Server extension.

No build step or dependencies are required.

Customizing
Colors: edit the custom properties at the top of css/styles.css under :root.
Projects: duplicate a project <div> inside .projects-container in index.html, then update the image, title and link.
Skills: duplicate a .languages block inside .skills-container, then update the icon and name.
